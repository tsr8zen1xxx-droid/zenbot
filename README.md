Zenbot — a personal AI assistant powered by artificial intelligence. Capable of conversing, answering questions, and analyzing uploaded images. Created by Zenix (Ilkhan).

Full (for GitHub README / Project description):

Zenbot is a smart AI web assistant built using Python and Streamlit.

Key Features:

💬 Smart Chat: Fast responses to queries, coding assistance, and general knowledge support.

📸 Vision & Image Analysis: Ability to see, analyze, and describe user-uploaded images.

⚡ Cross-Platform Interface: Responsive web layout optimized for both desktop and mobile devices.

❤️ Developer Support: Integrated donation panel to support ongoing project development.
